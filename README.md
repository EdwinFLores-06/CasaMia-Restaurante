# 🍽️ Casa Mia - Sistema Web de Gestión de Restaurante

## 📋 Descripción

Casa Mia es una aplicación web desarrollada como proyecto académico para la materia de Programación Orientada a Objetos.

El sistema permite la gestión integral de un restaurante mediante diferentes roles de usuario (Administrador, Empleado y Cliente), facilitando la administración de productos, inventario, pedidos, reservaciones, promociones y reportes.

---

### Backend

* Java
* Spring Boot
* Spring Security
* Maven

### Frontend

* HTML5
* CSS3
* JavaScript
* Thymeleaf

### Base de Datos

* MySQL

### Herramientas

* NetBeans IDE
* Git
* GitHub

---

## 👥 Roles del Sistema

### Administrador

* Gestión de empleados
* Administración de promociones
* Administración de combos promocionales
* Reportes de ventas
* Reportes de inventario
* Gestión completa del sistema

### Empleado

* Gestión del menú
* Control de inventario
* Administración de pedidos
* Administración de reservaciones
* Actualización de estados de pedidos

### Cliente

* Registro e inicio de sesión
* Visualización del menú
* Carrito de compras
* Realización de pedidos
* Reservación de mesas
* Consulta de historial de pedidos
* Consulta de promociones activas

---

## ⚙️ Funcionalidades Principales

### 🍕 Gestión de Menú

* Creación de productos
* Modificación de productos
* Eliminación de productos
* Organización por categorías

### 🛒 Sistema de Pedidos

* Carrito de compras
* Control de cantidades
* Generación de factura
* Historial de pedidos

### 📅 Reservaciones

* Reserva de mesas
* Validación de disponibilidad
* Administración de reservaciones

### 📦 Inventario

* Control de existencias
* Actualización automática de stock

* Promociones individuales
* Combos promocionales

* Ventas realizadas
* Pedidos registrados
